# FlexAI

FlexAI is a fitness-focused web app that combines workout support, AI-assisted food analysis, and social planning features in a single interface.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express
- SQLite
- Gemini API integration

## Features

- AI-assisted food analysis
- Camera-enabled flows
- Fitness and activity-oriented UI
- Local data support with SQLite-related tooling

## Development

Prerequisites:

- Node.js

Run locally:

```bash
npm install
npm run dev
```

Environment:

- Copy `.env.example` as needed for local setup
- Configure the required API keys before running production features
